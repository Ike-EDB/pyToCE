# Methodological Notes

This page provides the methodological notes and citation guide shipped with the
package and copied by `set_workspace(...)` into
`data_raw/methodological_notes/`.

The methodological notes refer to the underlying scientific article and its Methodological appendix,
which support the package implementation:

- {download}`Article <../src/pytoce/set_workspace/data/methodological_notes/pytoce_article.pdf>`:
  article providing the methodological basis for `pyToCE`.
- {download}`Methodological appendix <../src/pytoce/set_workspace/data/methodological_notes/pytoce_methodological_appendix.pdf>`:
  detailed methodological description of the framework and its use for
  monitoring and target setting.

## Citation

Please cite the article when using `pyToCE`, as it constitutes the
methodological basis for `pyToCE`.

Use the repository's {download}`CITATION.cff <../CITATION.cff>`
for the software citation.

## Additional Citations

For data source citations, see the recommended citation guide:

- {download}`Recommended citations <../src/pytoce/set_workspace/data/methodological_notes/recommended_citations.txt>`

## LCI workbook

{download}`LCI_per_unit.xlsx <../src/pytoce/set_workspace/data/methodological_notes/LCI_per_unit.xlsx>`
describes the per-unit inventories, quantities and sources used for polymer
production, conversion and end-of-life treatment. Its Read me sheet explains
the inventory tables, process boundaries and source references.

The workbook is shipped with the package and copied by `set_workspace(...)`
into `data_raw/methodological_notes/`.
